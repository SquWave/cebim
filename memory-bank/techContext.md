# Tech Context

## Technologies
- **Language**: JavaScript/JSX (ES6+)
- **Frontend Framework**: React 19 (Vite 7.3)
- **Styling**: Tailwind CSS 3.4
- **UI Components**: Lucide React (Icons), Recharts (Charts)
- **State Management**: React Hooks (Context API for Auth)
- **Backend/Storage**: Firebase Firestore (v12.8)
- **Authentication**: Custom Secret Key (SHA-256 Hashing via crypto-js) -> Firebase Auth (Anonymous)
- **PWA**: vite-plugin-pwa (Offline capabilities, Installable)

## Development Setup
- **Build Tool**: Vite 7
- **Package Manager**: npm
- **Linting**: ESLint 9 + React Hooks Plugin
- **Fonts**: Inter (Google Fonts)

## Key Dependencies
- `firebase`: ^12.8.0
- `react`: ^19.2.0
- `react-dom`: ^19.2.0
- `recharts`: ^3.5.0
- `tailwindcss`: ^3.4.17
- `crypto-js`: ^4.2.0
- `@yudiel/react-qr-scanner`: ^2.4.1 (QR Code Login)
